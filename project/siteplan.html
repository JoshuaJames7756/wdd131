Website Planning Document

Site Name

CodeStart Academy

The name "CodeStart Academy" represents a website designed to help beginners start learning programming and technology in a simple, organized, and accessible way.

Optional Domain Availability: codestartacademy.com

Site Purpose

The purpose of this website is to provide beginner-friendly information about programming and technology. Visitors will find educational content related to HTML, CSS, JavaScript, web development fundamentals, software development concepts, coding tips, and useful resources that help students improve their programming skills.

Scenarios

  • What programming language should I learn first as a beginner?
  • Where can I find free resources to practice HTML, CSS, and JavaScript?
  • What tools do web developers commonly use to build websites?
  • How can I improve my coding skills and prepare for a software development career?

Color Schema

Primary Color: #1E3A8A

This color will be used for headings, navigation areas, buttons, and footer elements.

Secondary Color: #F59E0B

This color will be used for highlights, accents, icons, and important visual elements.

Background Color: #F8FAFC

This color will be used as the main page background.

Typography

Poppins

Poppins will be used for page titles, headings, and navigation elements.

Arial

Arial will be used for paragraphs, lists, and general page content.
